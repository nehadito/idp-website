# IDP — Ideate Design Production

Responsive one-page website for IDP, ready for GitHub and Vercel.

## Deploy on Vercel

1. Upload this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Leave Framework Preset as **Other** and deploy.

## Update team photographs

Replace each `.photo-placeholder` block in `index.html` with an image. Keep the surrounding `.team-card` structure unchanged.

## Local preview

Open `index.html` directly in a browser or use any local static server.
